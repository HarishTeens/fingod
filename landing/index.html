Set up fingod

Needs Python 3 and a modern browser. Every connector is read-only. The prompt is PROMPT.md in the repo.

1 · Start your assistant inside the repo
git clone https://github.com/HarishTeens/fingod.git && cd fingod && claude

Starting inside the folder is what lets Claude Code load the project’s MCP servers. It asks you to approve them once.

Using Wallet? export WALLET_MCP_TOKEN=<token> first (Wallet app, Settings, MCP). Any other agent with shell access and MCP support works the same way.

2 · Paste the prompt
Read the prompt first

CH 03 · Questions

  
Before you paste it.

  

    
Is my data safe?
Your finances never leave your machine. The app runs in your browser and stores everything in a SQLite database in that browser. The files your assistant writes go into a data/ folder that git ignores. There is no account, server or analytics.

    
Can it place trades?
No. Every connector is read-only, and the instructions forbid order tools outright. Kite's server exposes them; fingod never calls them.

    
Which assistants work?
Claude Code, Codex CLI and Gemini CLI are set up out of the box: the repo ships each one’s project MCP config (.mcp.json, .codex/config.toml, .gemini/settings.json) and instructions (CLAUDE.md, AGENTS.md). Any other assistant with shell access and MCP support can follow the same prompt.

    
Why start the assistant inside the folder?
An assistant only loads a project’s MCP servers when its session starts in that folder, and you approve them at that moment. Cloning first and starting the assistant from inside it means the whole setup runs in one session, with nothing to restart.

    
Do I need every connector?
No. Pick the ones you use. Bitcoin, fixed deposits and Splitwise are just typed in. You can also look around first with the built-in demo data.

    
Why does it need Python?
Only for serve.py, a tiny static file server. Browsers won't load WebAssembly from a plain file, and the server also lets the app see the folder your assistant writes to. There is no backend and nothing to install.

    
What does it cost?
Nothing. It's open source under the Apache 2.0 license.
