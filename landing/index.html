Read-only by construction

The refresh routine never places, modifies or cancels an order — even if asked mid-run.

Resilient to a bad day

If one source is down, its sleeve is carried forward and marked stale, so the series never reads as a crash to zero.

Classified once

An unknown account blocks the checkpoint until you say what it is. A fixed deposit never gets quietly counted as cash.

Checkpoints

A snapshot, not a feed.

A checkpoint is an immutable record of every position on one date. Weekly, or whenever you ask. It never polls — and that is the whole trick.

Take it

Say “take a checkpoint”. Claude reads each source and asks for only what no server can supply.

Send quantity and price

Never a computed total. Value is calculated in Postgres as round(qty × price × fx, 2) and cross-checked against the source’s own number.

Diff against last time

Quantities that rose are money you added. Prices that moved are the market. Currency that shifted is FX.

Sales detected for free

A quantity that fell is a sale. fingod asks for the real exit price and books the realised gain on the exact shares sold.

Idempotent

Re-post the same date and it replaces. Re-ingest transactions and nothing duplicates.

Immutable history

Closing an FD stamps a date instead of deleting a row, so past weeks never silently rewrite.

Honest about gaps

Bought and sold between two checkpoints? It says plainly that weekly resolution can’t see that.

Since bought

Returns against true cost basis. US cost comes from the broker order book, FIFO’d at the exchange rate on each trade date — not a flat back-converted rate.

Realised gains

Every sale with its buy date, exit date, holding period and profit — by month or by year.

52-week price watch

Each refresh flags mega-cap US stocks near their low or deep below their high, and your gold ETF, so a falling knife doesn’t go unnoticed.

Drill into any sleeve

Open a sleeve to see every holding, sortable by value, cost, gain or weight.

Debt and gold, correctly filed

Liquid ETFs count as debt and gold ETFs as gold — matched by ISIN, not by ticker names that change.

Colour that stays put

Every sleeve keeps its colour across every chart, checked for colour-blind separation.

Local-first

Your data never leaves your machine.

No account, no cloud, no subscription. A Postgres database and a small Go service on your own computer, with a React dashboard on top.

Bound to localhost

Every container listens on 127.0.0.1 only. Nothing is exposed to the network.

Token on every route

All API calls need a bearer token generated on your machine. Secrets live in a private, gitignored .env.

Postgres is the record

Plain SQL migrations, exact NUMERIC arithmetic, and a schema you can inspect with any database tool.

git clone https://github.com/HarishTeens/fingod.git
make env      # once — fresh secrets
make up       # Postgres on 127.0.0.1
make migrate  # apply schema
make api      # Go API on :8080
make web      # dashboard on :5173
